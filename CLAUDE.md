# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

React + Vite static site for the cycling club. It has no backend in this repo.

## Commands

- `npm run dev`, `npm run build`, `npm run preview`. No lint or test script.

## Architecture

- `public/` and `src/` hold the site. `originals-full-res/` holds full-resolution images in the repo; check which assets the site actually references before changing them.
